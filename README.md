# Аудио для Zubrilka

Озвучка уроков из курсов [Zubrilka](https://color-zebra.github.io/frontend-quiz/) и тексты, из которых она сделана.
Отдельный репозиторий, чтобы основной не разрастался от переозвучек и чтобы ссылки на аудио пережили переезд
основного репозитория в приватный. План — `plans/audio-mode.md` в основном репозитории.

Файлы раздаёт GitHub Pages: `https://color-zebra.github.io/frontend-quiz-audio/…` — тот же сайт, что у приложения.

- MP3, моно, 48–64 кбит/с. Не через Git LFS.
- Переозвучили урок — новое имя файла: у тех, кто скачал курс на телефон, иначе останется старый.
- Рядом с `урок.mp3` — `урок.txt`, текст, из которого сделана озвучка.

`index.html`, `sw.js` и `test.mp3` в корне — временная страница проверки: фон при выключенном экране, кнопки на
экране блокировки, скачивание на телефон и перемотка из кэша. Уберём, когда проверка пройдена.
