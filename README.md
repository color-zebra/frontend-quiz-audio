# Аудио для Zubrilka

Озвучка уроков из курсов [Zubrilka](https://color-zebra.github.io/frontend-quiz/) и тексты, из которых она сделана.
Отдельный репозиторий, чтобы основной не разрастался от переозвучек и чтобы ссылки на аудио пережили переезд
основного репозитория в приватный. План и устройство — `plans/audio-mode.md` в основном репозитории.

## Как раскладывать

```
<курс>/                  — имя файла курса без .yaml, как в custom-sets/: system-design-basics/
  <id урока>.mp3         — озвучка урока
  <id урока>.txt         — текст, из которого она сделана: пересказ для слуха после подстановки словаря
  <id урока>.clean.txt   — тот же пересказ обычным русским, до словаря: из него заново собирают .txt, когда меняется словарь
dictionary-svetlana.md   — словарь произношения для голоса Светлана (Microsoft, edge-tts) — основной
dictionary-violetta.md   — словарь для голоса Виолетта (robivox) — запасной
probes.md                — журнал проб нейронки, из которых собран словарь
```

Правила текста для слуха — раздел «Текст для озвучки» в `plans/course-guide.md` основного репозитория.

В курсе у урока — ссылка через GitHub Pages (тот же сайт, что приложение, CORS не нужен):

```yaml
    audio: https://color-zebra.github.io/frontend-quiz-audio/system-design-basics/req-intro.mp3
```

- **Имя файла — по id урока,** который никогда не меняется. Порядковые номера в имени не нужны: уроки переставят,
  а имена останутся.
- **Переозвучка — новое имя:** `req-intro-2.mp3`, `req-intro-3.mp3` (и оба `.txt` с тем же номером), в курсе — новая
  ссылка. Под старым именем у тех, кто скачал курс на телефон, осталась бы старая версия, а GitHub Pages ещё
  несколько минут отдаёт закэшированный файл. Старый файл можно удалить, когда курс с новой ссылкой запушен: у кого
  курс ещё не обновлён, этот урок до «Обновить» будет играть только скачанным.
- **Формат:** MP3, моно, 48–64 кбит/с — урок на 10 минут весит 4–5 МБ.
- **Не через Git LFS:** GitHub отдаёт из LFS не файл, а указатель.
- **Пределы GitHub:** файл до 100 МБ (предупреждение с 50 МБ), сайт GitHub Pages — до 1 ГБ и около 100 ГБ трафика
  в месяц. Каждая переозвучка остаётся в истории git навсегда — репозиторий растёт и от удалённых файлов.

## Как собрать файл урока

Голос — Светлана (Microsoft, `ru-RU-SvetlanaNeural`) через пакет [edge-tts](https://github.com/rany2/edge-tts)
на Python: неофициальный бесплатный доступ к озвучке браузера Edge. Ударения и свою разметку он не принимает —
правила текста в разделе «Текст для озвучки» `plans/course-guide.md` основного репозитория.

Один раз — окружение (нужны Python и ffmpeg: `winget install Gyan.FFmpeg`):

```
python -m venv .venv
.venv/Scripts/python -m pip install -r tools/requirements.txt
```

Текст для озвучки из чистого текста урока — подстановка словаря Светланы:

```
python tools/derive.py system-design-basics/sdb-api.clean.txt
```

Пишет рядом `sdb-api.txt` и печатает, что проверить глазами: оставшуюся латиницу, омографы и формы, которые голос
читает неверно («стоит», «поля», «адреса» во множественном числе, «поднял»), единицы цифрами, числа от четырёх цифр,
вопросительные знаки. Синонимы, пересказ кода и таблиц, числа словами правят в самом `.clean.txt` и запускают снова.
Новое слово в `dictionary-svetlana.md`, которое можно подставлять механически, — новая строка в `REPLACE`.

Сборка урока:

```
.venv/Scripts/python tools/build.py system-design-basics/sdb-api.txt
```

- **Вход** — текст для озвучки: разделы урока через строку `=== раздел ===`.
- **Озвучка** — по разделу на запрос, по одному, с паузой 5 с; оборванный раздел (звук короче, чем должен быть)
  повторяется с нарастающей паузой. Завис — сервис молча не отвечает — запрос обрывается через две-четыре
  минуты (зависит от длины раздела) и тоже повторяется. **Не запускать несколько сборок разом:** доступ неофициальный, за долбёжку
  могут закрыть.
- **Кэш** — озвученные разделы лежат в `_raw/<курс>/sections/` по хэшу текста. Поправили один раздел — новый
  запрос только за него. `_raw/` и `.venv/` в git не идут.
- **Склейка** — 0,2 с тишины между разделами (Светлана оставляет ~0,6 с по краям, на стыке выходит ~1,4 с),
  громкость −17 LUFS, пики не выше −2 dBFS, MP3 моно 48 кГц 64 кбит/с, название урока и курса — в метаданных
  (из первой фразы «Курс «…». Урок «…».»).
- **Итог** — рядом с текстом, то же имя с `.mp3`; скрипт печатает длительность, размер, громкость и пики.

Первый урок (`sdb-intro.mp3`) озвучен голосом Виолетта на robivox и склеен вручную — команда ffmpeg и замеры
громкости для него в истории этого файла.

## Временное

`index.html`, `sw.js`, `test.mp3`, `sample.mp3` и `test-course.yaml` в корне — проверка озвучки на телефоне:
тестовая страница (фон, экран блокировки, скачивание и перемотка из кэша) и тестовый курс для приложения.
Уберём, когда проверка пройдена: `sw.js` перед удалением заменить на версию, которая отключает себя, — иначе на
телефоне останется обработчик.
