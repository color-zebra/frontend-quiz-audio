# Аудио для Zubrilka

Озвучка уроков из курсов [Zubrilka](https://color-zebra.github.io/frontend-quiz/) и тексты, из которых она сделана.
Отдельный репозиторий, чтобы основной не разрастался от переозвучек и чтобы ссылки на аудио пережили переезд
основного репозитория в приватный. План и устройство — `plans/audio-mode.md` в основном репозитории.

## Как раскладывать

```
<курс>/                  — имя файла курса без .yaml, как в custom-sets/: system-design-basics/
  <id урока>.mp3         — озвучка урока
  <id урока>.txt         — текст, из которого она сделана (пересказ для слуха, не текст урока)
```

В курсе у урока — ссылка через GitHub Pages (тот же сайт, что приложение, CORS не нужен):

```yaml
    audio: https://color-zebra.github.io/frontend-quiz-audio/system-design-basics/req-intro.mp3
```

- **Имя файла — по id урока,** который никогда не меняется. Порядковые номера в имени не нужны: уроки переставят,
  а имена останутся.
- **Переозвучка — новое имя:** `req-intro-2.mp3`, `req-intro-3.mp3` (и `.txt` с тем же номером), в курсе — новая
  ссылка. Под старым именем у тех, кто скачал курс на телефон, осталась бы старая версия, а GitHub Pages ещё
  несколько минут отдаёт закэшированный файл. Старый файл можно удалить, когда курс с новой ссылкой запушен: у кого
  курс ещё не обновлён, этот урок до «Обновить» будет играть только скачанным.
- **Формат:** MP3, моно, 48–64 кбит/с — урок на 10 минут весит 4–5 МБ.
- **Не через Git LFS:** GitHub отдаёт из LFS не файл, а указатель.
- **Пределы GitHub:** файл до 100 МБ (предупреждение с 50 МБ), сайт GitHub Pages — до 1 ГБ и около 100 ГБ трафика
  в месяц. Каждая переозвучка остаётся в истории git навсегда — репозиторий растёт и от удалённых файлов.

## Временное

`index.html`, `sw.js`, `test.mp3`, `sample.mp3` и `test-course.yaml` в корне — проверка озвучки на телефоне:
тестовая страница (фон, экран блокировки, скачивание и перемотка из кэша) и тестовый курс для приложения.
Уберём, когда проверка пройдена: `sw.js` перед удалением заменить на версию, которая отключает себя, — иначе на
телефоне останется обработчик.
